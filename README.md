# vscode-c2p
This example is the starting point for the implementation of graphics applications with C2P for Amiga OS 3.1.

The project reworks an old example of mine programmed with StormC 3.0 in 2007 and adapts it for the Visual Studio Code development environment on Windows with the Abyss / Job () extension.

You can find visual studio code extensions here: https://marketplace.visualstudio.com/items?itemName=JOB.amiga-debug-job
